# NŪRA Skin — storefront concept

A complete, production-quality front-end storefront for a fictional clinical skincare
brand. Built to demonstrate e-commerce UX and product merchandising: product pages with
variants, bundles with a routine builder, ingredient and benefits merchandising, and a
cart drawer with a full mobile shopping experience.

No build step, no framework, no dependencies. Open `index.html` and it runs.

---

## Running it

Because the site reads query strings (`product.html?id=…`), open it through a local
server rather than double-clicking the file:

```bash
# any static server works
npx serve .
# or
python -m http.server 8080
```

Then visit <http://localhost:8080>.

## Pages

| File | What it is |
| --- | --- |
| `index.html` | Home — hero, manifesto, bestsellers, benefits strip, actives, reviews, newsletter |
| `shop.html` | Collection grid — filter by type and concern, five sort orders, URL state, hover quick-add with variant picker |
| `product.html` | Product detail — gallery with three views, variant selector driving price/stock/CTA, quantity, accordions for benefits, key actives with percentages, how-to-use and full INCI, per-product reviews, sticky mobile buy bar |
| `routine.html` | Routine builder — three-step quiz (concern → skin type → effort level) that assembles a sequenced routine, explains each step, applies 15% bundle pricing and adds the whole routine to the cart. Plus four ready-made stacks |
| `about.html` | Science — formulation standard, process timeline, full ingredient glossary with deep links, exclusion list |
| `info.html` | Information template — journal, shipping & returns, FAQ, privacy, terms, accessibility, contact, stockists |

## Commerce behaviour

- **Cart drawer** — slide-in on desktop, full-height panel on mobile. Line items with
  quantity steppers, remove, free-shipping progress bar, subtotal, focus trap, `Esc` to
  close, focus restored to the trigger on close.
- **Persistence** — cart state lives in `localStorage` and survives navigation.
- **Variants** — each product carries its own variants with independent price and stock.
  One variant ships sold out to demonstrate unavailable-option handling; it stays
  visible, is struck through, and refuses selection with a message.
- **Bundles** — the routine builder and the ready-made stacks both compute a 15% bundle
  discount, show the individual total, the saving, and the bundle total.
- **Quick add** — from any grid: pick a size inline, add without leaving the page, cart
  badge pulses. Adding from a product page or a routine opens the drawer instead.

## Design system

- **Direction** — Heritage Apothecary. A Mayfair chemist's counter: parchment ground,
  an auction-catalogue voice, engraved rules, letterspaced capitals, and a deep bottle
  green colophon that closes every page. The clinical data is still all there — it is
  simply set like a ledger rather than a dashboard.
- **Palette** — parchment `#f3ede0`, surface `#faf6ee`, cream, sand; warm ink `#1b1813`;
  bottle green `#1e3a2b` as the brand ground, oxblood `#5b2a26` used rarely for
  marking, brass `#9c7b3c` for rules and seals. Brass as text uses `--brass-ink`
  `#6f551f`; muted `#615846` clears 4.5:1 on every ground. Tokens at the top of `main.css`.
- **Type** — one Garalde lineage, two cuts: Libre Caslon Display for headlines and the
  wordmark, EB Garamond for body, italic accents and every letterspaced-capital label.
  Figures are set old-style, as they would be in print. No sans, no mono.
- **Form** — one radius: zero. No gradients, no glass, no pills. The only shadow in the
  system is the cart drawer's, because the drawer genuinely floats. Product images sit in
  framed plates with an inner keyline, like mounted prints.
- **Imagery** — photography for atmosphere; brand-owned SVG renders for anything
  transactional, generated by `tools/gen-product-renders.py` from one studio system:
  parchment backdrop tinted toward the packaging, a single key light, grounded contact +
  ambient shadows, and archetypes matched to the physical product (pump, dropper, jar,
  tube, screw-cap bottle). Bottle green and oxblood do the differentiating. Three views —
  front, quarter turn, label macro — and each label carries the dose and size printed in
  the UI, set in a serif on a brass rule.
- **Memorable moment** — the brass seal: the monogram roundel in the header, and the
  engraved `N / NŪRA / EST. MMXIX` seal watermarked into the colophon.
- **Motion** — one quiet entrance for section heads and media via `IntersectionObserver`
  (12px rise, curtain wipe), a slim quick-add bar that eases up on card hover without
  touching the product image, a slow engraved-notices ticker, and drawer / mobile-menu /
  accordion transitions. Cross-document view transitions glide the next page in from the
  right where the browser supports them (Chrome, Edge today). Body scroll is locked with
  `scrollbar-gutter: stable`, so opening the drawer never shifts the page. Body copy does
  not animate. All of it collapses under `prefers-reduced-motion`.

## Accessibility

- Semantic landmarks, one `h1` per page, skip-to-content link
- Full keyboard operability with a visible focus ring; drawer and mobile menu trap focus
- `aria-expanded` / `aria-pressed` on every disclosure and toggle; `aria-live` on the cart
  count and routine summary
- Alt text on meaningful imagery, decorative imagery hidden from assistive tech
- Touch targets enlarged to ≥40px on coarse pointers
- Content renders without JavaScript — reveal animations are scoped to a `js` class
